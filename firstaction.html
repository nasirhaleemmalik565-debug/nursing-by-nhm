First / Initial Actions
FIRST / INITIAL ACTIONS
1. First action in an unconscious patient
Assess Airway, Breathing & Circulation (ABC)
2. First action in anaphylaxis
Administer IM Adrenaline
3. First action in cardiac arrest
Start CPR immediately
4. First action in severe bleeding
Apply direct pressure
5. First action in shock
Ensure airway & administer oxygen
6. First action in hypoglycemia (conscious patient)
Give oral glucose
7. First action in hypoglycemia (unconscious patient)
Administer IV Dextrose
8. First action in suspected stroke
Activate stroke protocol
9. First action in suspected myocardial infarction (MI)
Obtain a 12-lead ECG
10. First action in status epilepticus
Protect the airway
11. First action in burns
Cool with running water
12. First action in choking (conscious adult)
Encourage coughing
13. First action in choking (unconscious adult)
Start CPR
14. First action in snake bite
Immobilize the affected limb
15. First action in poisoning
Assess ABC
16. First action in acute asthma attack
Administer oxygen
17. First action in pneumothorax
Administer oxygen
18. First action in postpartum hemorrhage (PPH)
Perform uterine massage
19. First action in eclampsia
Maintain airway
20. First action in neonatal apnea
Stimulate the newborn
21. First action in febrile seizure
Place the child in lateral position
22. First action before blood transfusion
Verify patient identity
23. First action before administering medication
Verify the right patient
24. First action in hospital fire emergency
Rescue patients (RACE)
25. First action after needle-stick injury
Wash the site with soap and water
